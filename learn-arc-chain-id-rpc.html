Arc Chain ID and RPC endpoints (mainnet + testnet)

Arc mainnet went live on 16 September 2026. Here are the network parameters, confirmed by calling eth_chainId against the live RPCs — not copied from a blog post.

Network Chain ID Hex RPC Explorer
Arc Mainnet 5042 0x13b2 https://rpc.mainnet.arc.io https://explorer.arc.io
Arc Testnet 5042002 0x4cef52 https://rpc.testnet.arc.io https://explorer.testnet.arc.io

Verify it yourself in one command:

curl -s -X POST https://rpc.mainnet.arc.io \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
# {"jsonrpc":"2.0","id":1,"result":"0x13b2"}

0x13b2 is 5042. 0x4cef52 is 5042002. If your client shows anything else, you are pointed at the wrong network.

Add Arc to a wallet

{
  "chainId": "0x13b2",
  "chainName": "Arc",
  "nativeCurrency": { "name": "USD Coin", "symbol": "USDC", "decimals": 18 },
  "rpcUrls": ["https://rpc.mainnet.arc.io"],
  "blockExplorerUrls": ["https://explorer.arc.io"]
}

Note the native currency: USDC, not ETH. Arc has no separate gas token. Your users never need to acquire a second asset to pay fees — but every piece of tooling that assumes nativeCurrency.decimals === 18 being ETH needs a second look. See the decimals trap.

Add Arc to ethers

import { ethers } from "ethers";

const provider = new ethers.JsonRpcProvider("https://rpc.mainnet.arc.io", {
  chainId: 5042,
  name: "Arc",
});

Add Arc to viem

import { defineChain } from "viem";

export const arcMainnet = defineChain({
  id: 5042,
  name: "Arc",
  nativeCurrency: { name: "USD Coin", symbol: "USDC", decimals: 18 },
  rpcUrls: { default: { http: ["https://rpc.mainnet.arc.io"] } },
  blockExplorers: { default: { name: "Arc Explorer", url: "https://explorer.arc.io" } },
});

Getting testnet USDC

Testnet USDC comes from the Circle faucet at https://faucet.circle.com. You need it before you can send anything, because it is also the gas token.

Contract addresses

USDC's optional ERC-20 interface is at 0x3600000000000000000000000000000000000000 on both mainnet and testnet — which is a coincidence worth knowing about, because other addresses do differ.

Always read the canonical table rather than trusting a tutorial: https://docs.arc.io/arc/references/contract-addresses.md
